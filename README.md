# Travel Cost Predictor Using Machine Learning

## Project Overview
The Travel Cost Predictor is a beginner-level machine learning project that predicts the estimated cost of a trip based on distance, number of travel days, and mode of transport.

## Objective
To develop a machine learning model using Linear Regression to estimate travel costs based on different travel-related features.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Scikit-learn
- Google Colab

## Features
- Creates and processes a travel dataset.
- Checks and handles missing values.
- Converts transport categories into numerical values.
- Trains a Linear Regression model.
- Predicts the estimated cost of a new trip.
- Evaluates the model using Mean Absolute Error (MAE) and R² score.
- Visualizes actual travel costs and predicted costs using a graph.

## How It Works
1. A dataset containing distance, travel days, transport type, and cost is prepared.
2. The transport categories are converted into numerical features.
3. The dataset is divided into training and testing sets.
4. A Linear Regression model is trained on the training data.
5. The trained model predicts travel costs for new inputs.
6. The model's performance is evaluated, and the results are visualized.

## How to Run
1. Open the notebook in Google Colab.
2. Run all cells in order.
3. View the predicted travel cost, evaluation results, and graph.

## Dataset
This project currently uses a small sample dataset created for learning and demonstration purposes. More real-world data is required for reliable predictions.
